# @gik/provider-exploratory-graph

Exploratory-graph provider engine for the **Generative Interaction Kernel**. Evaluates choices and
options across a graph frontier and exposes an inspection view over the current frontier state.

```bash
npm install @gik/provider-exploratory-graph
```

```ts
import {
  evaluateExploratoryFrontier,
  inspectExploratoryGraph,
  type ExploratoryGraphDefinition,
} from "@gik/provider-exploratory-graph";
```
