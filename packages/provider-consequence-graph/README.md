# @gik/provider-consequence-graph

Consequence-graph provider engine for the **Generative Interaction Kernel**. Activates and blocks nodes
along typed consequence edges and exposes an inspection view over the resulting activation.

```bash
npm install @gik/provider-consequence-graph
```

```ts
import {
  activateConsequenceGraph,
  inspectConsequenceGraph,
  type ConsequenceGraphDefinition,
} from "@gik/provider-consequence-graph";
```
