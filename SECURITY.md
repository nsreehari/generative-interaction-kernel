# Security Policy

## Supported versions

GIK is under active development and has not reached its first stable release.
Security fixes are made on the current `master` line. Older commits, sample
tags, and prerelease package versions are not maintained as separate supported
release lines.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, or
pull request.

Use GitHub's private vulnerability reporting flow for this repository:

<https://github.com/nsreehari/generative-interaction-kernel/security/advisories/new>

Include the affected component and version or commit, reproduction steps,
impact, and any suggested mitigation. Do not include real credentials,
customer data, or other unrelated sensitive information.

The maintainers will assess reports and coordinate remediation and disclosure
based on severity and available maintainer capacity. This project does not
currently promise a fixed response or remediation SLA.
