# Support

GIK is an early-stage open-source project maintained on a best-effort basis.
There is no guaranteed response time or commercial support commitment.

## Where to ask

- Use a GitHub issue for reproducible bugs and focused feature requests.
- Include the affected package, version or commit, environment, minimal
  reproduction, expected behavior, and actual behavior.
- Use package README files and the repository `docs/` directory for usage and
  architecture guidance.

Do not use public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md)
for private reporting.

Questions about private applications, customer integrations, hosted services,
or infrastructure outside this repository are not supported by the GIK
framework project.
